# Pragyan Khanal - Portfolio

Welcome to the source code for my professional portfolio website.

This portfolio is built using Next.js, React, Tailwind CSS, and Typescript.

## Features
- **Hero Section**: A welcoming introduction.
- **Projects Section**: Showcases some of my GitHub repositories like `MY-PORTFOLIO`, `flutter-project`, `frontend-collaboration-project`, etc.
- **Responsive Design**: Designed to work gracefully on all device sizes.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
